# 中文知识图谱网页

## 参考图布局（当前界面）

首页现在使用 `static/dashboard.html`、`dashboard.css`、`dashboard.js`，沿用 `app.js` 的证据检索和画布交互。
包括左侧作物/知识视图/工具导航，顶部搜索和筛选，中间图谱与缩略图，右侧四类详情，以及底部路径、推荐和问答。
知识来源和农业数据仍为 V2，未复制参考图中的示例数量、未证实的因果链或无来源图片。

各工具均有实际操作：统计读取当前数据；对比比较两个实体的类型、关联和证据；导出下载 JSON（含证据）或 SVG；时空分布展示资料的适用地区与阶段；本体查看实际类型和关系。
未收录的其他作物显示明确空状态；用户菜单为本机访客信息，不假装存在登录系统。图片入口显示收录状态，当前无可用的已核对图片。
运行 `node test_dashboard.mjs` 可检查导航、详情标签、筛选、路径、问答、实体目录、缩略图、手机布局及实际 JSON/SVG 下载。历史侧栏布局测试不再适用于当前首页。

打开 **http://localhost:8090/**。这是项目自己的中文图谱工作台，7474 仍是 Neo4j 官方数据库管理工具。

当前使用 V2：搜索、地区/品种/阶段/类型/生效日期筛选、有向路径、证据详情和“问知识图谱”。画布最多显示 100 个匹配实体，可通过搜索和筛选定位其余实体。保留拖拽、平移缩放及手机布局。

侧栏筛选可组合使用，当前条件和匹配数量显示在“清空筛选”下方。快捷探索会重置旧筛选，然后进入选定专题；生产—采后专题包含采收、分选、包装、储藏、出库、运输和货架阶段。实体目录列出全部匹配实体，点击可定位并展开关联知识。作物、阶段实体会通过知识条目的适用条件检索。

路径查询继承关系类型、证据范围、地区、品种、阶段和日期；实体名称搜索、实体类型和快捷专题只控制浏览，不限定路径。无路径时会清空旧路径并显示说明；相同起终点会提示重新选择。改变筛选后，旧查询响应不会覆盖新结果。

数据来源、数量口径和完整启动步骤见 [V2 说明](../knowledge_graph/README-V2.md)。路径解释不等于已验证的因果效应，“问图谱”当前是确定性检索，未接入大模型。

## 启动

先在 agric 目录运行 `docker compose up -d --wait neo4j`。然后进入 `ai-service/graph_web`：

```powershell
# 前台运行，Ctrl+C 停止
py -3 server.py
# 或后台启动
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

Python 3.10+ 即可，无运行时第三方依赖，不依赖在线脚本或字体。后台日志位于 `logs/`。

默认绑定 `127.0.0.1:8090`，仅供本机使用。账号留在服务端，网页不返回数据库凭据。环境变量 `GRAPH_WEB_PORT` 可更改网页端口；`NEO4J_HTTP_URL`、`NEO4J_USER`、`NEO4J_PASSWORD` 可覆盖连接设置。默认沿用 Compose 中的本地演示配置，也识别 `LOCAL_NEO4J_PASSWORD`。

`GET /api/graph` 执行固定只读查询，读取 Neo4j 中 KGEntity 节点、关系及 Source 来源，刷新按钮重新读取数据。查询使用当前 Neo4j 5.26 支持的事务 HTTP 接口（官方已标为弃用，未来升级数据库时需迁移 Query API）。当前最多支持 1000 个农业实体、3000 条关系及 1000 条来源；超过限制返回错误，不静默截断。服务没有任意查询、写入或删除接口，也不会在数据库失败时回退到种子数据。

数据库数据源由 `../knowledge_graph/build_v2.py` 中核对后的条目生成到 `data/graph-v2.json`，再使用 `export_v2.py` 导出、导入 Neo4j，点击网页“刷新图谱”。Source 节点通过证据详情查看，独立 KGStatement 保留多元适用条件；主画布只展示领域实体及农业语义关系。

“本地已核对事实”只包含 local 范围且事实边已核对来源/本地专家审核的关系；异地资料不会自动变成本地结论。界面中的关系类型、审核状态、范围均提供中文解释，原始来源标题保留原文。

## 验证

后端测试：`py -3 -m unittest test_server -v`。

浏览器测试使用 Node 22+ 内置 WebSocket 和本机 Edge，无第三方测试依赖。以独立测试用户目录启动 Edge 无头模式（`--headless=new --remote-debugging-port=9229 --user-data-dir=<独立测试目录>`），再执行 `node test_browser_v2.mjs`。覆盖真实图谱、详情、搜索、地域隔离、有向路径、问答与手机宽度；截图保存在已忽略的 `test-artifacts/`。`test_browser.mjs` 仅为 V1 历史测试，不适用于 V2。
