# 泊头鸭梨 GraphRAG 原始文档库 V1

这是为"泊头鸭梨知识图谱 → GraphRAG"准备的第一批可追溯语料。

## 当前内容

-   4 份河北地方标准/标准元数据摘要
-   5 篇鸭梨采后与贮藏相关论文证据摘要
-   2 份政府农业/林业技术资料摘要
-   1 份河北农业大学相关病害资料摘要
-   `source_manifest.jsonl`：统一来源元数据
-   `chunks_v1.jsonl`：可直接用于第一轮 Embedding 的摘要级 chunks
-   `candidate_triples.jsonl`：候选关系，仅供人工复核后写入知识图谱

## 证据等级

-   A：正式标准或同行评议研究论文
-   B：政府农业技术资料 / 高校专业资料
-   C：较旧或地域适用性较弱的政府科普资料

等级表示"作为本项目证据源的优先级"，不是对论文质量的绝对评价。

## 最重要的原则

1.  这些文件是"证据摘要"，不是对原文的替代。
2.  取得标准/论文全文后，应按章节或条款重新切块，并保留页码/章节号。
3.  不要让 LLM 根据摘要自行补出温度、湿度、药剂剂量或百分比。
4.  因果边必须区分 `AFFECTS / PROMOTES / CAUSES`；证据不足时不要升级为
    `CAUSES`。
5.  `candidate_triples.jsonl` 中的关系必须人工审核后再进入生产知识图谱。
