# 350题论文阅读评测初稿

## 文件

- `test_questions_350.jsonl`：350条机器可读记录。
- `test_questions_350.csv`：Excel可直接打开，UTF-8 BOM。
- `测试题与答案350题.md`：题目、答案、来源及页码阅读版。
- `final_audit.json`：数量、来源分布、校验结果及文件哈希。
- `batches/`、`reviews/`：生成和第二轮审核中间记录；不能当正式题库。

## 质量边界（必须保留）

350道题的答案全部是本地论文切块中可逐字定位的原文，不是模型自由生成的农学回答；题意经过第二轮模型辅助复核，**尚无农业专家人工审定，不能称为已审定gold benchmark**。机器校验不能证明每个问法均无歧义，也不能证明论文结论本身正确。

其中333题标为研究记录，17题标为背景/转引讨论。后17题只能测试文献阅读，**不符合“本论文直接实验验证”的更严格口径，不得用于因果能力评分**。为了透明交付350题阅读初稿，显式保留此区别；若要求350题全部为独立实验结论，目前尚未达到。研究方法题也只是操作记录，不是田间因果效应。

来源为当前可解析的3篇论文：PAPER_001（122题）、PAPER_003（93题）、PAPER_005（135题）。未使用政府文章或标准冒充论文；未使用乱码论文、缺失全文、标记版面复核的块。覆盖以采后试验为主，无法代表完整田间农业问答分布。未为八类均衡凑数，环境风险/干预类可能为零。

`gold_entities` 是原文实体词候选，不是已完成图谱对齐的标准实体；`gold_sources` 仅列已发现的支持来源，不等于穷尽所有相关来源。reference_answer保留原文单位、条件、“可能”等表述。答案不能脱离试验品种、批次和处理条件作为生产指导。

当前 split=unassigned。禁止随机按题切分训练/验证/测试：同一论文的相近段落、同一事实的不同观察很容易泄漏，应按论文/实验/证据簇划分，并由人工标注者合并语义重复问题。带论文标题的问题适合有范围的阅读测验，可能人为降低来源检索难度；另建自然农户问法盲测集后才报告真实业务效果。

脚本位于 scripts/build_paper_qa.py、review_paper_qa.py、export_paper_qa.py。重新生成需DeepSeek API，缓存复用；不得将此模型生成集当作该模型独立能力的无偏证明。纯原文校验可运行 scripts/test_paper_qa.py。
