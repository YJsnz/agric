# 盐田丰语界面规范

官网 React 与工作台 Vue 共用 `shared/design-tokens.css`。前端原有变量在 `frontend/src/styles/_tokens.scss` 映射到公共变量；应用公共控件规则位于 `frontend/src/styles/design-system.scss`，官网 Tailwind 主题使用相同品牌色与字体。

| 用途 | 规则 |
| --- | --- |
| 主操作 / 选中 | 深青绿 `#2f6f5c`，悬停 `#245746` |
| 页面 / 面板 | 灰白 `#f3f6f4` / 白色 |
| 主文字 / 次级 | `#20392d` / `#52695e` |
| 分隔 / 浅选中 | `#dce6e0` / `#e8f1ec` |
| 字体 | 同一中文系统无衬线字体栈；代码使用等宽字体 |
| 圆角 | 控件 9px，卡片 14px，面板 20px；导航保持胶囊 |
| 层次 | 细边框、轻阴影；仅地图悬浮控件使用玻璃背景 |
| 状态 | 成功绿、警告琥珀、错误红；监控目标类别保留区分色 |
| 动效 | 操作约 180ms，进入约 300–450ms；尊重减少动态效果设置 |

监控的视频、摄像头预览与 3D 场景保留深色衬底；其窗口、表单和按钮与其他业务界面一致。Agent 深色主题覆盖公共变量，并统一个人面板及其卡片、表单、配置窗口。各模块保留原布局和操作方式。

新增业务控件应复用公共变量。不要为主按钮或选中状态新增独立蓝紫色，也不要使用旧页面的荧光色作为浅色面板上的正文。图表和状态色按含义保留，统一风格不应消除信息区分。
