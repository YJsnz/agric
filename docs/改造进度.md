# 盐田丰语改造进度

更新日期：2026 年 10 月 1 日。

## 问农界面第二版

参考 Harness 的 ChatView、HeroShell、InputBar 与主题样式重新实现 Vue 界面：中性侧栏、蓝色强调、统一消息/输入宽度、任务分组搜索、收起侧栏、移动抽屉、固定输入区、按调用 ID 合并工具记录、过程折叠和按需证据面板。新增深浅主题、配置说明弹窗、焦点恢复与键盘循环、Enter 发送和回答复制。

此版为参考交互结构后的独立实现，没有直接复制上游 React 组件。已通过前端类型检查、构建及真实浏览器交互检查，覆盖建议填入、配置开关、主题切换、移动侧栏搜索和横向溢出；对空白、完成、证据和深色状态进行了截图检查。

## 已交付的首期基础

- 固定并检查 DeepSeek Harness 参考源码，记录运行时选择 ADR。当前使用自有农业循环，尚未直接运行 DSH 核心。
- 接入本机 Ollama 的 Qwen2.5 7B，完成真实多轮工具调用。
- 农场查询、关键词资料检索、配置阈值核验三个白名单工具；从后端取得事实。
- MySQL 任务和事件记录、用户隔离、八轮预算、有界队列、取消、失败与重启中断标记。
- `/platform/assistant` 的任务列表、过程、证据、结果、重连与取消界面；旧工作台保留在 legacy 路由。
- 农场侧栏复用同一 Agent 任务 API，执行记录可在问农页查看。
- 独立测试数据库与 test.ps1，避免测试干扰演示任务。

## 验证依据

新增三项后端测试覆盖真实业务工具执行、事件序号/增量读取、跨用户访问、取消后迟到结果、非法工具与参数；与原测试合计 12 项通过。模型在测试中替换为可控响应，业务工具和数据库实际执行。

另外使用真实 Qwen2.5 7B 完成土壤湿度任务：读取农场 → 阈值核验 → 灌溉资料检索 → 模型最终回答，事件完整持久化。模型输出只能作为解释，当前阈值结果不能替代农艺判断。

前端通过类型检查与构建。桌面和 390px 移动页面采用浏览器检查，修正旧模式栏遮挡；保留已有农业场景。Agent 与原工作台按路由分包。

## 尚待实施

正式 farm membership、数据库迁移体系与历史观测；结构化 Decision 校验与 SSE；版本化文档/图谱/向量检索；鸭梨视觉模型与数据；风险/干预引擎；采后批次；GIS/遥感/运输；完整算法评测。

当前是共享演示农场，资料检索仍为关键词基线，无真实病害概率和设备操作。任务重启后保留记录并标记失败，不自动从中间步骤继续执行。首期不是完整方案的最终验收。

## 2026-10-01：数据工作台内容适配

保留原实景 / 3D、监控、设备、地块编辑、灌溉与告警处理。旧作物面板删除固定株高、LAI、病害低风险、固定采收日期和假农事记录；环境面板删除无历史支撑的趋势图和综合评分。专项 EC / pH、历史序列、视觉与采后缺失状态明确显示。不会自动重命名或覆盖用户已有地块与作物数据。

前端类型检查与构建通过；浏览器验证 8 个地块筛选定位、告警筛选、导出快照、Agent 预填、桌面 / 手机、3D 场景；没有页面运行错误。当前为内容与交互适配，不代表已完成 GraphRAG、风险模型、真实盐碱地数据或生产设备接入。

## 2026-10-02：地块边界校准

## 2026-10-02：真实梨叶视觉与果园 3D

接入固定版本公开梨叶 YOLOv8s 权重，转换为 ONNX Runtime CPU 推理，新增 Windows 安装与哈希校验。提供地块关联上传、异步队列、低质量图像复核、原图检测框、记录恢复、JSON 导出和公开叶片样例。原图和检测结果按用户隔离，保存模型与管线版本；当前类别为卷叶、叶片虫害与叶斑候选症状，尚无泊头鸭梨独立准确率评估，也没有果实分级、航拍诊断或真实摄像机接入。

官方 Harness 新增 get_vision_records，读取本人当前基地结果；指定一个视觉记录时绑定该记录 ID，近期列表最多 3 条。修正官方工具 DSL 的可选参数声明，并在 Java 最终输出前强制核验视觉与历史工具调用。实际 Qwen/Harness 任务完成基地上下文、资料检索和视觉记录读取；最终指定记录绑定变更通过单独回归检查，最后一次端到端复测遇到本机 GPU 满载并超时，没有保存未经核验的回答。

果园 Three.js 场景以校准后的二维地块多边形为源，加入鸭梨树、枣树、麦田、水渠、道路、包装冷链与采样设施；树木实例限制在地块内部。新增阻尼旋转、缓动缩放与聚焦、复位、自动总览取景、视觉记录标注及对应地块入口，保留原温室场景和工作台切换。坐标仍为概念投影，非 GIS 测绘。

验证：前端类型检查与生产构建；19 项后端测试；2 项真实 Harness 工具 DSL / 指定记录回归检查；图像质量拒识；浏览器实际上传到 CPU 推理、候选框、导出、Agent 预填、桌面 / 手机无溢出，以及 3D 选择、缩放、聚焦、复位和视觉联动。详见 [鸭梨视觉与3D](鸭梨视觉与3D.md)。
