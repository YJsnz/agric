# 田言耕智用户使用手册

> 文档版本：V1.0  
> 适用项目：田言耕智 · AI 原生智慧农业与数字孪生平台  
> 适用角色：农场管理人员、温室种植人员、设备运维人员、展示讲解人员、项目验收人员  
> 默认演示地址：`http://localhost:8081/`

---

## 1. 手册目标

本手册用于帮助第一次接触系统的用户，从打开官网开始，逐步完成以下完整体验：

1. 浏览官网并了解产品能力；
2. 注册账号并登录平台；
3. 选择是否绑定人脸；
4. 使用密码或实时摄像头刷脸登录；
5. 进入智慧农场数据工作台；
6. 浏览航拍实景和 3D 数字孪生；
7. 查询地块、大棚、设备、灌溉和告警信息；
8. 控制设备、执行自检、设置灌溉时长并处理告警；
9. 使用“小田”助手和独立“智能问农”工作台；
10. 进入每一座大棚，切换棚内实景与数字孪生；
11. 查看棚内环境、设备、分区和植株级数据；
12. 完成一次适合项目演示或验收的全流程操作。

本项目当前使用演示数据。环境指标会自动变化，设备开关、灌溉和告警操作会保存到数据库，因此刷新页面后仍可看到操作结果。

## 2. 使用前准备

### 2.1 推荐设备

| 项目 | 推荐配置 |
|---|---|
| 浏览器 | 最新版 Chrome、Edge 或 Firefox |
| 屏幕 | 1920×1080；最低建议 1366×768 |
| 网络 | 本机访问不需要互联网；AI 问农、人脸服务需要联网 |
| 摄像头 | 使用刷脸登录时必须具备可用摄像头 |
| 显卡 | 航拍模式无特殊要求；3D 模式建议使用支持 WebGL 2 的独立显卡 |

### 2.2 浏览器权限

首次使用时，浏览器可能询问以下权限：

- **摄像头权限**：刷脸登录需要；拒绝后无法刷脸登录；
- **麦克风权限**：智能问农语音输入需要；
- **全屏权限**：点击数据台全屏按钮后使用；
- **自动播放权限**：可能影响大棚实景视频自动播放。

### 2.3 确认系统已经启动

在浏览器访问：

```text
http://localhost:8081/
```

如果无法打开，请让系统管理员确认：

1. MySQL 容器正在运行；
2. Spring Boot 已监听 `8081`；
3. 没有第二个程序占用 `8081`；
4. 官网和平台前端已经构建。

## 4. 注册账号

### 4.1 打开注册页

有两种进入方式：

1. 在登录页点击“还没有账号？立即注册”；
2. 直接访问 `http://localhost:8081/#/sign-up`。

### 4.2 填写账号信息

依次填写：

1. **Full Name**：姓名或平台显示名称；
2. **Email Address**：登录邮箱，不能和已有账号重复；
3. **Password**：至少 6 个字符；
4. **Confirm Password**：再次输入完全相同的密码；
5. 点击 **Create Account**。

注册成功后，系统会自动保存登录令牌，并进入人脸绑定步骤。

### 4.3 绑定人脸（可选）

1. 浏览器弹出摄像头权限时点击“允许”；
2. 保持正脸位于取景框中央；
3. 避免背光、遮挡和多人同时入镜；
4. 点击“拍照”；
5. 检查照片是否清晰；
6. 不满意时点击“重拍”；
7. 满意后点击“绑定并进入”。

注册绑定场景允许上传一张清晰正脸照。如果暂时不绑定，可以点击“跳过，稍后在平台设置中绑定”。

## 5. 登录平台

![登录页面](./截图/登陆.png)

> **图 5-1　登录页面。** 左侧上方可切换“密码登录/刷脸登录”；表单下方是注册入口；“返回官网”用于退出登录流程。

### 5.1 密码登录

1. 打开 `http://localhost:8081/#/sign-in`；
2. 保持顶部选择“密码登录”；
3. 输入注册邮箱；
4. 输入密码；
5. 如需关闭浏览器后继续保持登录，勾选 **Keep me signed in**；
6. 点击 **Sign In**；
7. 登录成功后自动进入智慧农场数据工作台。

“Keep me signed in”的区别：

- 勾选：登录信息保存到浏览器本地存储；
- 不勾选：关闭浏览器会话后需要重新登录。

### 5.2 刷脸登录

刷脸登录只允许使用实时摄像头，不允许上传已有图片。

1. 在登录页选择“刷脸登录”；
2. 浏览器询问摄像头权限时点击“允许”；
3. 将正脸放在画面中央；
4. 保持光线均匀，摘下口罩、墨镜等遮挡物；
5. 点击“拍照”；
6. 查看预览，不清晰时点击“重拍”；
7. 点击“登录”；
8. 匹配通过后进入数据工作台。

如果摄像头无法打开：

1. 点击地址栏左侧的网站权限图标；
2. 将“摄像头”改为“允许”；
3. 刷新页面；
4. 重新进入刷脸登录。

### 5.3 登录失败处理

| 提示 | 处理方法 |
|---|---|
| 邮箱或密码错误 | 检查邮箱拼写、大小写和密码 |
| 该邮箱已被注册 | 返回登录页直接登录 |
| 无法打开摄像头 | 开启浏览器权限，确认摄像头未被其他软件占用 |
| 人脸未匹配 | 使用绑定过人脸的账号，改善光照后重拍 |
| 请求失败（401） | 登录已过期，重新登录 |

## 6. 数据工作台总览

![航拍实景数据工作台](./截图/主界面.png)

> **图 6-1　航拍实景数据工作台。** 顶部为全局操作栏，左上角切换实景和 3D，中央标签对应农场对象，右侧为当前对象详情，底部 Dock 对应七个业务中心。

进入平台后默认到达：

```text
/platform/workspaces/farm-01
```

请按以下编号认识界面：

1. **顶部全局栏**：品牌、模式切换、农场、搜索、通知、用户菜单和全屏；
2. **左上天气卡**：当前温度、湿度、风速、光照；
3. **中央农场场景**：航拍实景或 3D 数字孪生；
4. **场景对象**：大棚、地块、摄像头、设备、水池、气象站和机器人；
5. **视图切换**：实景与 3D；
6. **场景工具**：缩放、复位、图层、测距；
7. **底部业务 Dock**：总览、监控、环境、设备、灌溉、作物、告警；
8. **右侧上下文抽屉**：显示当前对象数据与操作；

1. 点击顶部搜索框；
2. 输入对象名称，如“2号温室”“水肥一体机”“蓄水池”；
3. 按 Enter；
4. 系统自动选中并聚焦对象；
5. 未找到时会显示提示消息。

### 6.2 通知

1. 点击顶部通知图标；
2. 查看最近三条告警；
3. 点击“查看全部消息”；
4. 系统切换到告警业务中心。

### 6.3 用户菜单

点击右上角头像，可以：

- 查看当前用户；
- 打开人脸管理；
- 绑定或解绑人脸；
- 退出登录。

## 7. 航拍实景模式

航拍实景用于快速理解整个农场的空间关系。

### 7.1 查看对象

- **鼠标悬停**：显示对象边界和摘要；
- **单击对象**：选中对象并打开右侧详情；
- **双击对象**：聚焦该对象；
- **点击空白处**：取消选择；
- **滚轮或工具按钮**：调整缩放；
- **复位按钮**：恢复农场全景。

### 7.2 图层控制

点击场景工具栏中的“图层”，可打开或关闭：

- 地块边界；
- 设备；
- 摄像头；
- 灌溉网络；
- 告警。

### 7.3 测距

1. 点击“测距”；
2. 点击第一个地图对象作为起点；
3. 点击第二个对象作为终点；
4. 页面提示两点之间的空间距离。

## 9. 七个业务中心

### 9.1 总览

用于查看：

- 农场健康度；
- 设备总数和在线数；
- 当前未处理告警；
- 水位和今日用水；
- 关键空间对象状态。

### 9.2 监控

1. 点击 Dock 中“监控”；
2. 地图上可监控的大棚和地块进入可选状态；
3. 点击一个大棚或地块；
4. 打开监控弹窗；
5. 查看视频、摄像头信息和 AI 检测框；
6. 可切换摄像头、查看 AI 分析或执行录像操作。

当前演示视频采用 YOLO 离线检测，并使用 ByteTrack 维持人员/作物目标 ID。检测结果会按视频时间叠加显示。

### 9.3 环境

点击“环境”后可查看：

- 空气温度；
- 空气湿度；
- 土壤湿度；
- 光照；
- CO₂；
- 24 小时趋势；
- AI 调控建议。

环境数据每 30 秒刷新一次。橙色或警示色表示指标需要关注。

### 9.4 设备

1. 点击“设备”；
2. 默认选中水肥一体机；
3. 从地图或设备列表选择目标；
4. 查看在线状态、位置、当前数值和最后通信时间；
5. 使用开关控制设备；
6. 点击“设备自检”执行检查；
7. 等待成功或失败提示。

安全限制：离线设备不能被开启。系统会返回“离线设备无法开启”，防止错误控制。

### 9.5 灌溉

1. 点击“灌溉”；
2. 查看蓄水池、水肥机、阀门和各灌溉单元；
3. 选择一个灌溉单元；
4. 设置灌溉时长；
5. 打开或关闭灌溉；
6. 保存计划；
7. 刷新页面确认状态仍然保留。

### 9.6 作物

选择“作物”后可查看：

- 作物品种；
- 生长阶段；
- 健康度；
- 环境摘要；
- 病虫害风险；
- 当前农事任务。

选择大棚后，可通过详情中的“进入大棚”继续查看棚内植株。

### 9.7 告警

1. 点击“告警”；
2. 查看告警标题、时间、等级和状态；
3. 选择未处理告警；
4. 阅读关联对象信息；
5. 点击“处理告警”；
6. 状态变为“已处理”；
7. 刷新后处理结果仍然保留。

## 10. 右侧上下文抽屉

右侧抽屉根据选择对象自动变化。

### 10.1 大棚或地块

显示：作物、面积、生长阶段、环境、健康度和任务。大棚详情下方提供“进入大棚”。

### 10.2 设备

显示：在线状态、启停状态、测量值、位置、最后通信时间、控制开关和自检。

### 10.3 灌溉单元

显示：目标区域、运行状态、流量、时长设置和计划保存。

### 10.4 告警

显示：事件等级、关联对象、发生时间、当前状态和处理操作。

关闭抽屉后，3D 第一人称控制会自动恢复。

## 11. 智能问农

![独立智能问农首页](./截图/问农.png)

> **图 11-1　独立智能问农首页。** 中央输入框用于自然语言提问，下方提供常用问题快捷入口；左侧保存项目和最近对话，底部 Dock 可进入面板、演示及其他应用。

系统提供两种问农入口：

1. 数据工作台左侧“小田”助手；
2. 顶部“智能问农”独立页面。

### 11.1 在数据工作台中提问

1. 点击“小田”角色；
2. 输入问题；
3. 点击发送；
4. 系统会自动携带当前视图、业务模块和已选对象；
5. 查看回答；
6. 继续追问即可形成多轮对话。

示例问题：

- “当前农场有哪些异常？”
- “2号温室为什么需要关注？”
- “分析4号地块土壤湿度。”
- “给我一个今天的灌溉建议。”
- “当前有哪些离线设备？”

### 11.2 独立智能问农页面

1. 点击顶部“智能问农”；
2. 点击“新建对话”或选择历史对话；
3. 输入自然语言问题；
4. 可使用快捷问题；
5. 可点击麦克风进行语音输入；
6. 可添加文本附件；
7. 发送后查看文字回答和自动生成的数据面板；
8. 使用右侧快捷 Dock 打开应用、数据或相关功能；
9. 对话和工作台布局会保存到当前账号。

不同账号的问农记录相互隔离。

![自定义智能工作台](./截图/自定义工作台.png)

> **图 11-2　自定义智能工作台。** 工作台可同时承载告警、灌溉计划、大棚状态、农场总览和关键指标组件；点击右上角“编辑工作台”可调整组件，底部“小田助手”可结合当前面板继续提问。

### 11.3 AI 不可用时

如果提示未配置或调用失败，请管理员检查：

- `DEEPSEEK_API_KEY`；
- `DEEPSEEK_BASE_URL`；
- `DEEPSEEK_MODEL`；
- 服务器是否能够访问模型接口。

## 12. 进入大棚内部

进入方式有两种：

### 12.1 从详情按钮进入

1. 在航拍或 3D 场景单击一座大棚；
2. 打开右侧详情；
3. 点击“进入大棚”；
4. 系统进入对应大棚内部页面。

### 12.2 在 3D 中双击进入

1. 切换到 3D；
2. 找到目标大棚；
3. 双击大棚模型；
4. 系统进入对应大棚内部。

六座大棚分别使用独立作物和结构：

| 大棚 | 作物/用途 | 模型特点 |
|---|---|---|
| 1号 | 番茄 | 藤蔓番茄与栽培架 |

## 13. 大棚内部操作

![大棚内部数字孪生](./截图/大棚内部.png)

> **图 13-1　大棚内部数字孪生。** 顶部切换实景/数字孪生；中央为高精度作物和棚内设备模型；底部显示环境指标；右侧标签分别进入总览、设备和植株数据，右栏内部可独立向下滚动。

### 13.1 页面结构

1. **顶部栏**：返回农场、大棚名称、智能问农/数据工作台、实景/数字孪生；
2. **中央主画面**：棚内实景视频或 3D 模型；
3. **底部环境条**：温度、湿度、土壤/基质含水、光照、CO₂；
4. **右侧数据栏**：大棚概况、设备、分区、植株、建议和告警；
5. **侧栏收起按钮**：扩大主画面；
6. **返回农场**：返回园区数据工作台。

### 13.2 实景模式

1. 点击顶部“实景”；
2. 等待摄像头/演示视频连接；
3. 查看棚内真实画面；
4. 如果浏览器阻止自动播放，点击“播放棚内实景”；
5. 观察摄像头连接和 AI 在线状态。

当前版本播放预置棚内视频。后续计划接入 LingBot-Map，将单目摄像头视频转换为棚内三维重建结果，并服务于农业机器人定位和导航。该规划不代表当前页面已经完成实时建图。

### 13.3 数字孪生模式

1. 点击顶部“数字孪生”；
2. 拖动旋转模型；
3. 滚轮缩放；
4. 点击植株，在右栏打开植株数据；
5. 查看棚架、苗床、滴灌、传感器、风机、相机和控制设备。

### 13.4 右侧“总览”

包括：

- 大棚面积、棚型、栽培模式和健康度；
- 生产画像；
- 平均株高 7 日趋势；
- A/B/C 分区作业；
- AI 调控建议；
- 最近告警。

### 13.5 右侧“设备”

1. 点击“设备”；
2. 查看在线设备数量；
3. 逐项查看设备名称、位置、责任、运行状态和实时值；
4. 对照数字孪生中的空间位置理解设备布局。

### 13.6 右侧“植株”

1. 点击“植株”；
2. 查看样本总数和需关注数量；
3. 点击一个植株编号，如 `P-03`；
4. 3D 模型定位到对应植株；
5. 查看健康度、株高、基质含水、株龄、叶面积指数和建模坐标；
6. 点击“取消定位”恢复普通浏览；
7. 使用鼠标滚轮或拖动右栏滚动条继续查看下方植株。

### 13.7 收起和展开数据栏

- 点击右栏左侧中部的箭头可收起；
- 再次点击可展开；
- 右栏内容过长时，把鼠标放在右栏内部滚动；
- 手机和平板上可直接在右栏上下滑动。

## 17. 常见问题

### 17.1 页面打不开

- 确认地址为 `http://localhost:8081/`；
- 确认后端已经启动；
- 如果日志出现“地址已在使用”，说明已有实例占用 8081，不要重复启动；
- 强制刷新：Windows/Linux 使用 `Ctrl+F5`。

### 17.2 页面只有官网，进入不了平台

- 检查是否登录；
- 检查浏览器是否禁用了本地存储；
- 重新访问 `/#/sign-in` 登录。

### 17.3 3D 黑屏或模型不完整

- 更新显卡驱动；
- 确认浏览器开启硬件加速；
- 检查浏览器是否支持 WebGL 2；
- 关闭其他占用显存的软件；
- 切回航拍实景继续操作。

### 17.4 大棚右栏不能滚动

- 将鼠标移入右栏后再滚动；
- 不要在中央 3D 画面上滚动；
- 手机上直接在右栏区域上下滑动；
- 强制刷新以确保加载最新 CSS。

### 17.5 实景视频不播放

- 点击画面中央播放按钮；
- 检查浏览器自动播放设置；
- 确认 `greenhouse-monitor.mp4` 静态资源存在。

### 17.6 AI 问农失败

- 普通数据台功能不受影响；
- 联系管理员配置 DeepSeek Key；
- 检查服务器联网状态。

### 17.7 联系表单发送失败

- 检查网络；
- 确认 FormSubmit 已在收件邮箱激活；
- 直接发送邮件到 `1478838114@qq.com`。

## 18. 数据和安全提示

- 演示环境数据不代表真实农业生产参数；
- 执行真实设备控制前必须增加权限、审计、联锁和现场急停；
- 不要将管理员密码、JWT 密钥、DeepSeek Key 或百度人脸 Key 告诉普通用户；
- 刷脸功能涉及生物特征数据，正式部署前应取得用户授权并制定删除机制；
- 生产决策应由农业专业人员结合现场情况确认，AI 建议不能替代人工责任。
