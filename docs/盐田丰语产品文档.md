# 盐田丰语 Jetson 展示版产品文档

版本 0.2 部署候选  
编制日期 2026年10月3日  
适用对象 展示负责人 软件开发人员 设备集成人员

本产品把农业数据工作台、可追溯业务记录、具备工具调用能力的 Agent、梨叶候选症状检测和植物园 3D 空间集成在同一应用中。当前目标是用一台 Jetson 和浏览器完成稳定的软件展示。数据与设备动作采用演示模式，不依赖真实传感器，也不把模拟回执当作现实执行证明。

展示版选择 Jetson Orin Nano Super 8GB、主动散热和 NVMe SSD。Jetson 承担服务和本地推理，优先由独立电脑浏览器展示 3D。代码已加入边缘部署与 TensorRT 路径；当前验证来自 Windows CPU 环境，Jetson GPU 和本地 Qwen3 的性能尚待实机验收。

## 产品定位与用户

主要用户是项目讲解人员、评审与参观人员。讲解人员需要在有限时间内演示从观测、查询、业务记录到视觉复核的完整链路；参观人员需要看到明确的数据来源和任务状态。软件开发及设备集成人员负责配置运行环境、管理版本和执行验收。

展示版保留原工作台切换与工作面板，业务模块采用统一侧栏。将智能问农和数据工作台放在同一基地上下文中，便于从场景对象进入任务，再回到记录查看依据。

| 模块 | 当前能力 | 展示边界 |
| --- | --- | --- |
| 数据与墒情 | 概览 观测历史 地块及阈值核验 | 使用演示观测 不承诺真实测量 |

| 种植与采后 | 农事 生长 批次登记和流转追溯 | 数量与状态由软件登记 |
| 告警 | 查看及处理 保存处置记录 | 规则告警不是诊断结论 |
| 智能问农 | 工具查询 资料检索 任务追问与重试 | 只读工具 不自主创建业务动作 |
| 视觉检测 | 上传和摄像头采样 候选框 历史及人工复核 | 梨叶近照症状 不能确诊 |
| 3D 空间 | 植物园园景 地块对象 导览与漫游 | 概念坐标 不是真实 GIS 测绘 |
| 运维 | 诊断 开机服务 发行清单 备份脚本 | 尚未达到工业整机交付标准 |

## 关键展示流程

建议按六到八分钟的顺序展示。先在数据工作台选择鸭梨基地，查看墒情、设备与告警，说明数据为软件演示。再进入种植登记农事或生长观察，创建一条采后批次并推进采收、分选、入库和出库，刷新页面确认追溯记录仍在。

随后切换智能问农，提出查询已保存采后批次的任务。界面展示计划、工具过程、检索依据和答案；批次回答需包含数据库编号与状态。可以继续追问或导出任务记录。Agent 输出不能声称已经控制设备或完成现实作业。

接着进入独立病虫害功能，上传固定梨叶样本或打开网页摄像头，进行单次及连续采样。展示候选框、置信度、原图和人工复核记录。最后进入植物园 3D，完成导览、漫游、对象选择和视图切换，返回工作台导出记录。

## 展示设备选型

| 部件 | 展示配置 | 选择原因 |
| --- | --- | --- |
| 主机 | Orin Nano Super 8GB 开发套件 | 满足展示优先的成本与体积目标 |
| 存储 | 256GB NVMe SSD | 保存模型 依赖 数据与版本 |
| 电源与散热 | 原装电源及主动散热 | 长时间展示需要稳定供电和散热 |
| 页面客户端 | 笔记本或台式机浏览器 | 降低 Jetson 上 3D 与推理资源竞争 |
| 摄像头 | 页面客户端摄像头或 USB 摄像头 | 对应当前网页采样链路 |
| 网络 | 局域网及可信 HTTPS | 远端浏览器摄像头需要安全上下文 |

该配置是工程选型，尚无整机报价、功耗或帧率承诺。Jetson 的共享内存需要同时容纳操作系统、数据库、Java、视觉与大模型，因此默认仅允许一个 Agent 任务执行。暂不采用多路视频、多个大模型或本地 7B 以上模型作为展示基线。

## 模型与计算方案

视觉路径共用图像质量检查、letterbox 预处理和类别 NMS。Windows 使用 ONNX Runtime CPU，Jetson 选择 TensorRT FP16。常驻 Python 进程复用模型、CUDA 缓冲区和流，减少连续采样中的重复加载。前后处理仍由 CPU 执行，没有把整条链路宣称为全 GPU 或零拷贝。

本地 Agent 基线为 Qwen3 4B Q4_K_M，使用 llama.cpp CUDA 服务和官方 DeepSeek Harness。默认上下文 4096 token、单次输出 512 token、关闭长思考。工具包括农场上下文、环境分析、资料检索、业务记录和视觉记录。边缘配置精简地图几何与资料片段，完整工具结果仍保存在任务记录中。也可以改成 OpenAI 兼容的远端服务，保留原 Qwen2.5 配置。

JetPack 6.2.1 基线和计算版本依据 NVIDIA 发布说明。Qwen 量化文件来自官方 GGUF 仓库，固定版本并校验哈希。TensorRT 引擎在目标板生成并检查来源模型与运行版本，不把桌面生成物直接复制到板端。

## 记录与权限

登录账号使用 JWT 和密码哈希。视觉原图、结果与复核按用户隔离；任务查询和工具读取验证用户与基地。农事、批次及工作台属于共享展示基地，不支持企业租户隔离，不应存放多个客户的私有生产数据。

业务记录保存于 MySQL，图像、模型与运行文件单独持久化。批次只允许按既定顺序推进，复核追加记录并保留原始结果。任务重试创建新任务，历史结果不覆盖。发行包排除用户数据和密钥。

## 部署与使用

交付物包括 Java 静态页面发行包、Harness 源码与依赖锁、ONNX 模型、板端安装和 systemd 服务脚本、配置示例、SHA 256 清单及部署验收手册。首次安装需要网络获取依赖和本地大模型；准备完成后核心展示使用本地服务。

部署人员先刷写指定 JetPack，再安装运行依赖、生成随机密钥、在板端编译 llama.cpp 和 TensorRT 引擎，启动数据库及两个服务。首次创建展示账号后可以关闭公开注册。局域网访问由 Nginx 提供可信 HTTPS，数据库与模型端口仅监听回环。

日常使用前确认软件环境诊断与样例任务通过。使用后备份数据库和视觉原图，单独保管密钥。升级保留旧发行版本，先备份，再切换版本；数据库结构回退须恢复匹配快照，不能只切换 JAR。

## 验收标准

| 验收项 | 通过标准 | 当前状态 |
| --- | --- | --- |
| 后端业务回归 | 身份 观测 批次 Agent 视觉测试通过 | 28 项通过 |
| Harness 参数与工具 | 工具 schema 与边缘预算测试通过 | 3 项通过 |
| Python 推理 | NMS 格式拒绝 常驻多帧与错误恢复通过 | 3 项通过 |
| 摄像头流程 | 采样 推理 连续检测 停止与后台释放 | Windows 模拟摄像头回归通过 |
| Jetson GPU | FP16 输出与 CPU 比较通过 | 待上板 |
| 板端稳定性 | 两小时无 OOM 队列与界面可用 | 待上板 |
| 本地大模型 | 真正调用工具并引用返回事实 | Qwen3 板端待验收 |
| 视觉性能目标 | 暖机 p95 不超过 500ms | 待实测 |
| Agent 性能目标 | 标准单任务 180 秒内完成 | 待实测 |

性能目标用于安排验收，不表示目前已经达到。图像数值比较要求相同类别、框 IoU 至少 0.9、置信度差不超过 0.03。还需记录型号、功耗模式、版本、温度、内存以及三次重复基准。已有 Windows CPU 延迟只能帮助检查脚本，不可替代板端指标。

## 商业产品化前置工作

当前成果适合展示和试用。面向正式销售，还需要角色与租户授权、注册和登录的完整防护、版本化数据库迁移、自动恢复演练、设备身份与升级签名、日志脱敏和容量保留策略，以及长期稳定性与失效测试。真实设备控制应另行建设协议、权限、确认和执行回执，不能延伸解释现有模拟按钮。

模型许可也需完成发行审查。Qwen3 官方模型标注 Apache 2.0；当前公开梨叶来源仓库附 MIT 许可，同时构建链使用 Ultralytics 并保留 AGPL 3 文本。来源仓库的许可不能自动消除训练工具或权重的发行义务。商业版本须完成权重来源与授权核验，必要时替换成授权明确的模型，不能把现有演示检测器直接表述为已通过商用合规。

梨叶模型尚未经过泊头鸭梨专项验证，不能对外宣传准确诊断率、病害概率或农药剂量建议。工业整机还需按销售场景完成相应可靠性、安全与认证工作。后续范围由实际客户与设备要求确定。
