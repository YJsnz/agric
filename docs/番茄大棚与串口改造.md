# 番茄大棚与串口改造

鸭梨二号园沿用 `yt-pear-02`，初始化器只迁移默认同名地块，已有自定义名称的记录不自动覆盖。新的默认地块类型为 greenhouse、作物为番茄；旧农事和运输 ID 保持可关联。通过地块详情的“进入大棚”进入内部场景。

棚内 4 床 × 8 株，共 32 株，每一株都有稳定 P 编号、位置、品种和演示长势数据。棚内不再生成无法点选的填充番茄。采用项目作物建模框架并补充番茄锯齿复叶（茎、叶、果、花、棚架、水肥设备），新增 WASD / 方向键巡检、畦床碰撞限制、Esc 退出；拖拽观察、滚轮靠近、点选档案。这里的植株档案与环境值仍为演示数据，未伪装成真实逐株监测。

整体 3D 农场中该地块改为拱棚阵列，含棚架、覆盖材料、作物行和吊蔓。地块边界与既有运输道路沿用校准坐标。航拍背景是 AI 概念效果图，不能作为 GIS 或测绘底图。

番茄视觉组件与两个冻结 V1 权重来自 `origin/feature/wjm-multicrop-ai`，仅提取番茄服务与权重，没有合并旧分支其余文件。通过现有多作物代理与统一 Python 服务运行，可选择叶片症状或果实成熟度，加载时核验 SHA256；结果为视觉候选。原分支真实测试依赖未随仓库提供的外部评估集，缺失时明确跳过，另以合成图像验证两份真实权重的推理接口；不把合成图测试当成准确率验证。

实景地图支持拖拽平移、滚轮缩放、触控单指拖拽、缩放上下限和边缘约束。缩放与拖动不会允许露出背景外的空白。外围采用生成的宽幅农田续图。底图是概念图，图片生成造成的地物差异不能视为真实地理变化。

图片使用内置 imagegen 工具生成，资产已复制到项目：

- `frontend/public/assets/yantian-greenhouse-aerial.png`：番茄温室航拍原稿。
- `frontend/public/assets/yantian-greenhouse-expanded.png`：地图实际使用的单张宽幅农田全景，避免拼接边界。
