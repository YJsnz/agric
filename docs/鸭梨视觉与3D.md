# 鸭梨视觉与地块 3D

## 使用

在数据工作台点击独立的「病虫害」，选择鸭梨地块并上传 JPEG / PNG 叶片近照。支持最大 8 MB、2000 万像素。图像只存本机 `var/vision/<任务ID>`，结果与拥有者、基地、地块关联并保存到 MySQL。刷新可恢复记录，服务重启会将未完成任务标记失败。「监控」保留原多视角、截图、录像和回放设计，当前播放原有示例视频，与病虫害功能分开。

切换「摄像头」后点击「开启摄像头」，允许浏览器访问内置 / USB 摄像头。支持设备选择、采集单帧检测、连续采样检测。连续模式等上一帧任务结束后再间隔 5 秒采样，逐帧保存到同一记录系统；不承诺实时视频帧率。检测框只叠加在对应采样图上，预览画面不复用旧框。关闭摄像头、关闭窗口、切换输入方式或切到后台会释放摄像头；停止连续检测后已提交的帧仍正常保存。需使用 localhost 或 HTTPS。尚无园区 RTSP / NVR 拉流与部署接入。

检测结果显示候选类别、置信度、原图像素框、模型版本、模型和文件 SHA-256、推理耗时。低置信度未检出、曝光或尺寸不足返回「需要复核」，不会判为健康。可以导出 JSON，或预填问题让 Agent 读取本人记录并检索资料。

「试用公开梨叶样例」使用注明 CC BY 4.0 来源的本地图像，走相同的上传与真实推理流程。记录列表显示本人当前基地最新 50 条；Agent 的最近记录查询最多 3 条，指定一个记录 ID 时工具绑定该 ID，避免模型漏传参数而混入其他检测。

切换 3D 后，地块由二维多边形通过概念图像投影生成，同一地块 ID 用于选择、档案和视觉入口。支持旋转、缩放、缓动聚焦、复位与记录数量标注。种植实例只生成在多边形内部，摄像机与设施按图像位置映射；保留原温室 3D。图像投影不是 GIS 标定，场景长度与档案面积不能当作实测数据。

## 模型与适用范围

采用 [Wb-az 的公开梨叶检测项目](https://github.com/Wb-az/yolov8-disease-detection-agriculture)，固定 commit `a435fd29d197dd7bcab016cd86e30f87c1f3ce7c` 的 `yolov8-pear-experiments/grid-opt/weights/best.pt`。训练配置为 YOLOv8s，类别来自权重：`curl`、`slug`、`spot`，分别作为卷叶、叶片虫害和叶斑候选症状展示。上游数据来源为 [Fenu 与 Malloci 的 DiaMOS Plant](https://zenodo.org/records/5557313)。

原权重 SHA-256：`ffd36dc94e3d242d6f88954a67da73db73fcb038f7500cc01486316148cbf866`。ONNX SHA-256 和转换后的类别保存在 `vision-runtime/models/manifest.json`；结果同时保存运行管线版本 `pear-leaf-cpu-1.1`。

在线使用 ONNX Runtime CPU，2 个计算线程，640×640 letterbox，置信度阈值 0.55，同类 NMS IoU 0.45，最多 50 个候选框。推理队列单并发、最多 8 个等待任务，超时 90 秒。推理无需联网，也不依赖 Ollama。Agent 仍使用独立的 Qwen/Harness 服务。

这是公开梨叶症状模型接入，尚无泊头鸭梨独立测试集，因此不能声称已验证鸭梨病害准确率。它不适用于果实外观分级、整园航拍、病斑面积分割、病害概率、农药选择与剂量。对于非叶片等域外图像，阈值拒识只能降低部分误检，不能保证全部拒识；仍需核对拍摄对象与农技复核。

## Windows 安装

安装 Python 3.11 后运行 `start.cmd -Task VisionSetup`。首次安装会下载固定权重、CPU PyTorch 和转换依赖，校验权重哈希并导出 ONNX；后续有模型时只检查运行依赖和哈希。`-RebuildModel` 可重新转换。正常 `start.cmd` 已加入安装步骤；`-SkipBuild` 使用已安装环境。

运行依赖固定于 `vision-runtime/requirements.txt`。重型 PyTorch / Ultralytics 只用于模型转换，在线推理只导入 ONNX Runtime、NumPy 和 Pillow。`VISION_PYTHON` 可指定解释器绝对路径，`VISION_STORAGE` 可指定持久图像目录。ONNX、环境与图像不进入 Git，离线迁移需一起备份模型目录和图像目录。

上游项目 MIT 许可证随模型保存在 `UPSTREAM-LICENSE.txt`；离线转换使用 Ultralytics 8.3.203，AGPL-3.0 许可证保存在 `ULTRALYTICS-AGPL3.txt`。模型分发需同时保留上游出处、许可证和运行依赖许可。

## 验证记录

工程验证使用公开 [pear-pests-dataset](https://huggingface.co/datasets/salahkhenfer/pear-pests-dataset) 的验证分区叶片图片（CC BY 4.0，作者提供图像及标注，出处保存于本地测试目录）。验证目的为真实模型运行、坐标与接口链路，并非鸭梨准确率评测；数据类别与本模型标签不完全相同，不能直接把检出率算作准确率。

运行 `vision-runtime/.venv/Scripts/python.exe vision-runtime/check.py` 检查无细节、低曝光、小图拒识；后端测试验证拥有者 / 基地隔离、具体记录读取、重启中断恢复；浏览器验证上传到推理、检测框、导出、Agent 引用、手机布局与 3D 联动。
