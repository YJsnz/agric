# 自动导航运输系统 · 软件仿真

入口：数据工作台 → 设施侧栏 → 自动导航运输车。2D 小车也可点击进入。

## 当前实现

单车差速运输仿真，地块取送货、仓储交接、库存预留、任务队列、空载返航充电、暂停、急停、确认装卸、自动装卸选项及运输历史。数据保存在数据库 `transport_states`，切换页面或关闭弹窗后任务继续；重启后从保存位置继续，不跳过交接。

支持鸭梨、小枣、旱碱麦、设施蔬菜、肥料和农具。每项库存使用独立单位，公斤和件不混算。初始库存明确为演示库存；单任务载荷暂按登记数量上限500限制，不作为真实车辆额定载重。

## 地图约束

采用1536×1024图像概念坐标，批准路段连接地块边缘装卸点、采后仓库、农资仓和停车点。田地读取服务器当前地块多边形；建筑使用配置禁区，河道使用图像边界禁区。v6 路网按底图可见的服务路、田埂和装卸前场标定，共24段，7个展示地块同步重划。路段宽16图像单位，车身安全包络半径5；可行驶中心偏离路段不超过3。

全局规划校验整段车身扫掠包络并每3图像单位采样检查；执行时对每个预测子段进行连续扫掠检查，避免两个安全采样点之间穿过地块角点。新增或修改地块后，路线重新接受边界校验。无合法路径不能创建运输任务，受阻时停车，不能穿田或沿直线抄近路。当前道路为示意路网，没有GIS或实测标定，不用于实车。

2D、3D共用服务器任务与位置。3D通过已有 `imageToGround` 映射，同时依据局部投影比例调整车身示意尺寸；车辆和道路不会各自独立运行。植物园新增园景会避让运输路线。

## 算法

- 全局：道路图A*，欧氏距离启发；过滤封闭路段、不安全车身包络和障碍占用路段。仓库前设置合法备用通道，可在路口重新规划。
- 局部：DWA风格速度与角速度采样。速度0、12、24、36、48图像单位/秒，并按剩余距离减速；角速度−1.5、−0.75、0、0.75、1.5弧度/秒。预测一个控制周期，分5个子步检查碰撞、道路边缘和禁区。
- 加速限制：每秒24图像单位/秒。控制周期约500ms，超时步长上限1秒。路口先减速转向，不平滑切角穿田。
- 障碍：静态道路障碍、模拟横穿道路行人；安全距离包含障碍半径、车身半径和附加余量。道路不足以绕开时停车等待。到合法节点可A*改道，中途不越界绕行。
- 调度：单车任务队列，最多8个未结束任务。当前没有多车会车或路口预约功能。

这不是完整ROS2 Nav2控制栈；后续接真实机器人时需替换定位、传感器、速度执行和地图标定接口。

## 仓储与库存

建任务：预留源库存，不扣减总库存。取消待调度或未装货任务：释放预留。

装货确认：释放预留，扣减源库存，写OUTBOUND流水，货物进入在途状态。

卸货确认：增加目标库存，写INBOUND流水，任务完成。重复装卸请求被拒绝，避免重复记账。

自动装卸仅模拟交接，不控制夹爪或设备。已装货的任务不能直接取消，需完成交付；行驶中可以暂停或急停。解除急停后按任务“继续”恢复。

采后管理 → 贮藏管理显示运输到采后仓库的交接库存。运输库存和采收批次流转分别记账，当前未把任意散装货物强行关联成已有采后批次。

## 运输车运动表现

2D保留斜侧视透明图片，叠加随实际行驶距离滚动的轮毂辐条、方向箭头和轻量车身起伏。暂停／急停不再累计轮转；原地差速转向时两侧轮子反向转动。方向角使用最短角度插值，经过±π时不绕一整圈。

3D使用独立轮胎滚动组与前轮转向枢轴，轮胎／轮毂／辐条／胎纹分别建模，转动半径按世界坐标中的真实渲染尺度计算。辐条和胎纹使用实例化绘制，避免每个细节都产生单独绘制请求。车身只做轻微悬挂起伏，服务端车位不由动画改变。导航仍是差速仿真，前轮视觉转角用于增强转向表现。

### 3D运输车独立网格模型（2026-10-14）
