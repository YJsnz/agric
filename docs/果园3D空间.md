# 果园 3D 空间

数据工作台右上角切换到 **3D**。当前场景沿用二维地块的边界、业务对象 ID 和资料入口，保留原温室基地的独立 3D 场景。

## 已实现

- 鸭梨、金丝小枣、旱碱麦分区种植。果树包含树皮纹理、七组分枝、十二组叶团、一百片独立叶片和八颗带梗果实；鸭梨采用旋转曲面与果皮斑点纹理，小枣采用红色果实。麦田使用多茎与逐粒麦穗实例。
- 果园细叶按观察距离显示，地面漫游在精细与均衡档显示，流畅档关闭细叶；树干、分枝、叶团、叶片和果实分别实例化，不逐树创建完整模型。
- 基地底座沿场地外轮廓收边，包含环场道路、双层围栏、路灯、田间通道、路缘、铺装接缝、种植行床、水渠护岸、服务桥、闸门和岸边芦苇。入口和鸭梨观测区有中文实体标牌。
- 分选包装中心、冷库、采样站和泵站包含纹理屋面、光伏电池网格、门窗立柱、卷帘门、雨槽、排水管、装卸月台、护柱、冷库风扇与格栅、托盘周转筐和停放的运输拖车。泵站增加外置储罐、管线、阀轮和泵组。
- 气象站包含百叶防辐射罩、三杯风速计、采集箱和太阳能板；摄像头包含支架、镜头和遮阳罩；阀门组有独立低位箱体、管线与阀轮。设施按业务对象分别建模并保留可点击身份。
- 树皮、土壤、铺装、屋面、果皮、标牌和水面使用本地程序化纹理，不依赖远程模型或贴图下载。叶片轻摆、水面波纹遵循系统减少动态效果偏好。
- 建筑零件按模型与材质合并，环境围栏与管线合并绘制；离开场景时释放纹理、几何和材质。
- 自动巡场逐一访问六个地块，每处停留约 6.5 秒；拖动场景、全景复位、缩放、打开业务面板会停止巡场。页面隐藏也停止巡场。
- 地面漫游支持 WASD 移动、左右方向键转向、Shift 加速、Esc 退出；触屏方向按钮支持按住移动、松开停止。打开面板、失去窗口焦点或页面隐藏时暂停，必须点击“继续漫游”才恢复。
- 地面视角限制穿越基地边界、水渠、建筑安全范围与树干；位置示意图显示当前相对位置。跨渠桥包含桥面高度与连续坡道，漫游会平滑调整视线高度；尚未提供建筑室内导航，也不是精确物理仿真。
- 标注优先保留选中对象、避让相邻标注与屏幕边缘；地面视角中，建筑与树冠遮住的标签不显示。可随时隐藏标注，地块定位列表保留全部入口。
- 漫游时数字 1–7 连接原业务模块，打开业务面板后暂停移动；退出漫游恢复进入前视角。横竖屏切换退出漫游并重新适配全景，避免保留错误镜头。
- 左下角可直接定位地块、复位与缩放，移动端保留这些入口。
- 地块边界、设备标签、摄像头、灌溉管网和告警标记联动工作台图层开关。关闭设备标签保留实体建筑。
- 选中对象后可点击“定位近景”观察模型细节；点击对象连接原有数据面板；选中鸭梨地块后，可打开同一地块的梨叶视觉工作室。
- 支持平滑镜头过渡、减少动态效果系统偏好、后台停绘、闲置降帧与离开页面释放渲染资源。

## 坐标与能力范围

这是根据概念航拍图反投影建立的演示空间，未接入实测 GIS、测绘模型或真实摄像头标定。道路、水渠与设施细节是示意模型；场景单位不能用作真实面积或距离。自动巡场是镜头巡视，不代表设备正在执行巡检。灌溉图层只展示管线，不执行控制指令；摄像头图层只展示设备位置，尚未提供真实视场标定。

## 代码位置

- `frontend/src/components/workspace/OrchardDigitalTwin.vue`：渲染、实例植被、建筑、选择、巡场与控件。
- `frontend/src/components/workspace/orchardModels.ts`：共享纹理材质、果树麦田、建筑设备及模型零件合并。
- `frontend/src/components/workspace/orchardSiteDetails.ts`：道路路缘、行床、路灯、闸门、岸边植物及实体标牌。
- `frontend/src/components/workspace/orchardNavigation.ts`：地面漫游碰撞约束。
- `frontend/src/components/workspace/orchardEnvironment.ts`：底座、外围道路、围栏、水渠桥梁、灌溉支管。
- `frontend/src/components/workspace/orchardGeometry.ts`：二维到三维投影与多边形内采样。
- `frontend/src/views/FarmWorkspaceView.vue`：图层与业务面板联动。

## 验证

前端 TypeScript 检查与生产构建通过；浏览器检查覆盖全景、缩放、聚焦、关联视觉记录、巡场切换、设备图层、移动端布局与运行错误。补充验证覆盖键盘移动、转向、触屏移动、窗口失焦与业务面板暂停、Esc 退出、标注开关、2D/3D 切换，以及 10 项导航几何检查。测试截图与脚本位于忽略提交的 `target/`。

## 模型细化验证（2026-10-03）

生产构建通过。Edge 无头浏览器全景约 185 次绘制、88 万三角形，地面近景约 126 次绘制、75 万三角形（含阴影相关绘制，数值随视角与图层变化）。近景、设施图层、减少动态效果和手机漫游均实际渲染；无着色器错误。重复切换 2D/3D 后纹理数保持为 9。此验证不代表所有移动设备上的固定帧率。

细化仍采用统一风格的程序化演示模型，未升级为真实基地的摄影测量模型。设施、果实数量、结构尺寸和管网细节均为示意，不作为生产实测档案。

## 植物园环境改造（2026-10-03）

3D 环境改为“果园植物园”，二维概念航拍、原地块边界、设备 ID、业务资料和试验田用途继续沿用。

- 灰色底座改为带细纹理的自然灰绿色草地；草地延伸到外围缓起伏地形，补充背景树林，使环境不再浮在空白背景上。
- 田间空地与园路两侧布置混合花境、灌木和观赏树，保留鸭梨、旱碱麦与金丝小枣作为专题展区。
- 增加温暖石色环园游步道、曲线庭院连接道、藤蔓廊架、休憩座椅、小池塘、岸石与浮叶花；入口实体标牌改为植物园导览标牌。
- 空地选择避开种植区、主通道、水渠和设施保留范围，庭院与池塘需要足够安全间距才生成；主环园步道向边界收紧，避免切入种植区。
- 左下角“园景导览”可直接查看“花境庭院”和“静水花园”。观赏树、廊架柱和座椅进入碰撞限制，小池塘禁止直接踏入。
- 景观植物只是演示模型，未加入生产作物档案或设备台账；外围植被不会扩大实际业务地块或漫游许可边界。

生产构建通过。植物园浏览器验证覆盖两处园景导览、近景、手机漫游、减少动态效果以及三次 2D/3D 切换；另有布局检查验证庭院、池塘、观赏树避开生产地块、设施与服务道路。最终测试全景约 207 次绘制、127 万三角形（包含阴影），反复切换后几何数和纹理数保持一致，未发现浏览器运行或着色器错误。

园景生成逻辑位于 `frontend/src/components/workspace/botanicalGarden.ts`。这是园林风格的演示改造，不是实测景观设计或真实植物栽培方案。

## 植物园细节与漫游完善（2026-10-03）

- 花境增加成对细叶和弯曲叶形；池塘增加浅底、泥岸、浮叶与不规则岸石，渠岸补充碎石和挺水植物，并避开桥头通路。
- 跨渠桥重新对齐两岸，增加两端坡道与正确方向的护栏；水域仅允许从桥面通行，视线高度随坡道平滑变化。运输拖车、周转筐和外置储罐纳入碰撞范围。
- 园景导览新增“水岸桥”，三处园景均支持“从此处漫游”。
- 标注避让天气、导航、位置示意图、业务面板、底部入口和工具栏，选中标注也不覆盖这些界面。
- 增加自动适配、精细、均衡、流畅画质设置并保存选择；自动模式在桌面使用均衡、窄屏使用流畅。各档调整像素比、阴影和细叶显示，减少高分辨率屏幕的渲染负担。

桥面、水域限制和坡道连续性检查通过；浏览器验证覆盖画质切换与保存、三处园景、桥面漫游、界面避让、手机布局和运行错误。测试桥面视线高度为 2.625 场景单位。相同全景下精细档约 152 万、流畅档约 127 万三角形（包含阴影相关统计）；这不是帧率测试，真实低配置设备仍需实机验证。

细叶生成位于 `frontend/src/components/workspace/gardenUnderstory.ts`。实测 GIS、真实设备数据与建筑室内模型仍未接入。
